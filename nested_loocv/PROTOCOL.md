# Locked Nested LOOCV protocol

Five cancer-versus-Control tasks, all 1,550 controls per task and 136/223/159/122/98 cancers respectively (8,488 outer predictions). No sampling or class/sample weights. Source columns after the four metadata fields are the molecular inputs. Historical feature definitions/model families remain conditional study choices; this is internal validation, not external validation.

Outer leave-one-patient-out. Inner stratified 80/20 holdout random_state=42 on outer training. Fscore, ANOVA, ReliefF (10 neighbors), Binomial (BD) supervised rankings use inner training ONLY. K caps in src/protocol.py exactly match revised none; incremental XGBoost K search (50 rounds, early stop 10, train-validation AUC gap >0.1 for 10 consecutive iterations or 5 consecutive decreases); first strict maximum determines K. Then all five AutoGluon 1.1.1 families are evaluated for each method's optimized K (20 candidates). No time limit or reduced search in smoke tests. AutoGluon default hyperparameters match none; only computational CPU/thread allocations change from 2 to 1, GPU=0. No weighting or balancing. Each feature generator is explicitly fitted on inner training before AutoGluon receives validation.

Selection lexicographic descending AUC, AP, Recall, healthy Specificity rounded at 12 decimals, then ascending K, method order Fscore/ANOVA/ReliefF/Binomial, model name, as in revised none. Binary argmax assigns probability exactly 0.5 to Control. This tie convention is saved in predictions; clinical sensitivity at threshold 0.5 uses score >= 0.5 explicitly.

After locking method/K/model, rerank ALL outer training patients with the selected method. Fit fresh preprocessing on the selected outer-training feature columns. Refit base model templates with inner-selected trained rounds/epochs using AutoGluon convert_to_refit_full_template, on every outer-training patient, X_val=None, no weights. For WeightedEnsemble, retain inner-validation-selected ensemble weights (the meta-model selection) and refit every positively weighted constituent on ALL outer training using newly ranked features. Re-estimating ensemble weights on outer training fitted predictions would introduce resubstitution bias; no such estimation is performed. FastAI's native full-refit path adds two training-row copies as validation placeholders only, not as optimizer training rows; every original outer-training patient occurs once in its optimization dataset. Outer test is used only for the final prediction.

Atomic per-fold SUCCESS requires patient identity, labels, finite probabilities, 20 candidates, feature count, split isolation and artifact SHA256 checks. Full ranking, K curves, model metadata, feature identities, split IDs and actual model-fit inputs are retained. Temporary model files are removed after each attempt. Each subprocess handles one fold; retries (3 attempts per invocation) are isolated. Restart validates and skips successful folds. No reuse of supervised rankings across folds.

Aggregate ROC AUC/AP use pooled OOF predictions, never single-fold AUC averaging. CIs: 2,000 patient-level true-class-stratified bootstrap replicates, conditional on fitted OOF scores; they omit part of training/selection uncertainty and dependence between overlapping training folds. No independent-fold t-test. Reports fail closed until every expected fold for that task passes validation.

Clinical stages are joined exactly on SampleID from the original clinical workbook. Missing stages stay missing. Stage n<10 is exploratory and independent AUC is suppressed. Stage I/II/I-II/III are compared with all corresponding OOF controls. Fixed specificity 95%/97% thresholds are retrospective/exploratory thresholds derived from pooled OOF controls, not independent calibrated validation; each bootstrap resamples controls and cases separately and reestimates threshold. Confidence intervals therefore describe these retrospective statistics only.
